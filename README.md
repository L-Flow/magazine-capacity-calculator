# 弹仓静态容量计算器

这是一个基于 C++17、OCCT 和 Qt 的轻量化弹仓容量分析项目。第一阶段建立两个互相对照的结果：

1. **FCC/HCP 理想排列参考**：搜索规则最密晶格的平移相位，给出规则排列参考数量。
2. **无摩擦准静态沉降**：保留重力方向、球体不重叠和仓壁约束，忽略质量、弹性、恢复系数和真实摩擦。

当前版本支持 STEP（以及 SDK 含 `TKDESTL` 时的 STL）内腔模型。对单一有效 solid，导入模型后，在三维窗口左键选择弹丸进入面，再输入重力方向并应用。模型会被变换到局部重力坐标系：局部 `-Z` 是重力方向，局部 `+Z` 是向上，因此不再要求 SolidWorks 使用固定的 Y 轴建模。

对于整车 STEP 装配体，程序会把多个零件作为障碍物，并根据用户确认的多个边界面提取目标弹仓自由空间。视图中普通左键单选面，按住 Ctrl 左键可追加或取消面；选中的面会以黄色持续高亮。确认后，程序把这些面作为有限的局部边界证据，结合面片切向范围、实体障碍物和入口连通洪泛建立局部连通区域，不再把局部面错误外推成无限平面，也不再依赖一个难以定位的鼠标射线空腔点。装配体整体拓扑即使存在局部无效零件也会先允许导入；选中边界附近及面片包络内的零件会被纳入局部障碍，未被所选边界包围的外部空间不会进入求解区域。

对于多面边界模式，第一张选中面用于建立局部水平基准；每张选中面都会按实体两侧试探，保留其自由侧方向。多面确认后，选中面按单侧边界墙参与洪泛，并按各面的切向范围取交集，避免长车体面把目标外包成大矩形；选中面包络的上沿还会结合重力方向建立虚拟入口闸门，防止开放腔体向整车外部泄漏。提取后求解坐标原点会裁剪到目标连通组件的局部包围盒，显示模型和弹丸同步平移。单体负模型仍把选中的第一张面作为入口参考面，并允许入口面相对重力方向倾斜。

当前求解目标是静态容量：假设弹丸最终能够到达无摩擦准静态平衡位置；入口面不是逐颗粒动态流动仿真边界。装配体球壁检查使用精确实体内点分类，并对接近壁面的候选使用局部三角网格距离检查；网格只用于加速距离查询，不能替代入口/重力方向的正确标注。若要研究侧向或倾斜入口造成的“进不去/堵塞”，还需要增加入口射线注入和可达性分析。

## 构建核心与测试

```powershell
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure
build\packing-cli.exe 170 100 80 17
```

CLI 参数依次为弹仓内部宽度、深度、高度和弹丸直径，单位均为毫米。

## 构建 Qt/OCCT 演示界面

本机已有环境可以复用：

```powershell
cmake -S . -B build-gui -G Ninja `
  -DMAGAZINE_BUILD_GUI=ON `
  -DMAGAZINE_OCCT_ROOT="C:\Users\Lenovo\Documents\和良\.analysis\occt-sdk-complete-7.9.3" `
  -DCMAKE_PREFIX_PATH="C:\Users\Lenovo\Documents\和良\.analysis\.WorkflowQt\5.15.2\msvc2019_64"
cmake --build build-gui
```

构建完成后可直接运行：

```powershell
build-gui\magazine-capacity-gui.exe
```

人工操作顺序：

1. 点击“打开 STEP / STL”，选择弹仓内腔负模型或整车装配体。
2. 点击“选择弹仓边界面（Ctrl+左键多选）”。普通左键选择一个面，Ctrl+左键继续追加或取消；黄色高亮面应围成目标弹仓的底面、侧壁和必要的顶面。确认高亮面没有选错后再继续。
3. 对多实体整车装配体，点击“点击高亮内壁生成内部点（多实体必选）”，再单击黄色高亮的目标内壁面。程序从 OCCT 命中的真实面交点沿法向两侧探测自由侧生成红点；二维鼠标位置不再承担三维深度，点到透明空白或未高亮面会被拒绝并提示。
4. 输入重力向量 `(X, Y, Z)`。方向只看向量方向；当前车体 STEP 的默认值为 `(0, 0, -1)`，其他模型按实际姿态修改。
5. 点击“确认边界面并应用重力方向”，程序会根据所选边界面和内部点提取空间，再运行 FCC/HCP 或准静态沉降。

命令行可用以下形式测试装配体提取，其中 `face-index` 是按 OCCT 面遍历顺序的零基索引：

```powershell
build-gui-ninja-v2\cad-capacity.exe --assembly model\底盘装配v0.STEP face-index gx gy gz 17 8
```

最后两个参数分别是弹丸直径和连通网格尺寸，单位为毫米。只验证空间提取而不运行容量搜索时，在末尾增加 `--extract-only`。GUI 中不需要手动输入面索引，直接点选即可；若选中的面不能判断出自由侧，程序会报错并要求重新选择内壁面。
